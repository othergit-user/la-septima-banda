# La Septima Banda

Campaign and ticket-funnel project used as the first real-world test case for AplusGlobalConnect.

## Source material

- `Personal MindMap Notes/7th/`
- `Personal MindMap Notes/AplusGlobalConnect-Organized/02-La-Septima-Banda/`
- `septima-banda-phoenix-deploy.zip`

## Status

Creative packages, asset manifests, handoffs, and synthetic ticket QA exist. The campaign is not production-ready until the authorization checklist is complete.

## Folders

- `campaign/`: briefs, captions, audience, and publish plan
- `assets/`: approved images, video, and manifests
- `production/`: storyboard, edit, and delivery packages
- `ticket-funnel/`: ticket site, checkout, QR, and analytics contracts
- `qa/`: synthetic and production verification
